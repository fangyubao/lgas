# usb_task.c 测试指令

只给测试人员看发送指令，不展开代码逻辑。

说明：

- 帧头固定：`0x78`
- 第 2 字节：命令号
- 后续字节：参数
- 以0x40结尾
## 1. 获取版本号

简介：读取系统版本字符串。

发送指令：

```text
78 01 40
```

## 2. 获取时间

简介：读取当前 RTC 时间。

发送指令：

```text
78 02
```

## 3. 设置时间

简介：设置 RTC 时间。

格式：

```text
78 00 YY YY MM DD HH MM SS
```

示例：

```text
78 00 20 26 04 14 15 30 45
```

## 4. 设置串口波特率

简介：设置指定串口的波特率。

格式：

```text
78 03 uart_port baud_sel
```

示例：

```text
78 03 02 03
```

## 5. 获取 CH4 信息

简介：读取 CH4 设备信息。

发送指令：

```text
78 04
```

## 6. 设置 CH4 地址

简介：设置 CH4 的从机地址。

格式：

```text
78 05 new_id
```

示例：

```text
78 05 05
```

## 7. 获取 C2H6 数据

简介：透传一帧到 C2H6 模块并返回结果。

格式：

```text
78 06 len data0 data1 ...
```

示例：

```text
78 06 03 01 02 03
```

## 8. 设置 DAC 输出

简介：设置 DAC 输出电压值。

格式：

```text
78 07 data_h data_l
```

示例：

```text
78 07 03 E8
```

## 9. 设置风扇占空比

简介：设置风扇占空比。

格式：

```text
78 08 duty
```

示例：

```text
78 08 64
```

## 10. 设置气泵占空比

简介：设置气泵占空比。

格式：

```text
78 09 duty
```

示例：

```text
78 09 64
```

## 11. 设置电磁阀占空比

简介：设置电磁阀占空比。

格式：

```text
78 0A duty
```

示例：

```text
78 0A 64
```

## 12. 设置 DG408 通道

简介：切换 DG408 地址。

格式：

```text
78 0B ch
```

示例：

```text
78 0B 01
```

## 13. 获取 C2H2 数据

简介：读取 C2H2 模块数据。

发送指令：

```text
78 0C
```

## 14. 获取 CH4 浓度

简介：触发 CH4 浓度采集。

发送指令：

```text
78 0D
```

## 15. 获取 C2H2 浓度

简介：触发 C2H2 浓度采集。

发送指令：

```text
78 0E
```

## 16. 获取 C2H6 浓度

简介：触发 C2H6 浓度采集。

发送指令：

```text
78 0F
```
